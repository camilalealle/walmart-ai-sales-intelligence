# Walmart Sales Explorer: web version

Standalone version of the Tableau Data App built with Tableau Studio. It has the same design and interactions, and it reads a static data snapshot (`data.json`) instead of the published Tableau Cloud data source, so anyone can open it without a Tableau account.

- `index.html`, `src/app.js`, `src/styles.css`: the app (code generated by Tableau Agent, adapted to load static data).
- `data.json`: weekly sales by store and department (Jan 6 – Oct 26, 2012), generated from `data/processed/walmart_sales_2012.csv` with `scripts/build_web_data.py`.

Validation (no filters): Total Sales $558.4M · 45 stores · 15 departments · Sales per Sq Ft $95.24 · Holiday Lift +0.9%. All values match the Python analysis.

Regenerate the data:

    python scripts/build_web_data.py data/processed/walmart_sales_2012.csv docs/data.json

Preview locally (`fetch` needs a server, so opening the file by double-clicking won't work):

    python -m http.server --directory docs 8000
